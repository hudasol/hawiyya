# Notice for data files

`data/samples/population.csv.gz` is derived from synthetic patients generated by Synthea
(https://github.com/synthetichealth/synthea), which is licensed under the Apache License,
Version 2.0. Only five columns are kept: a synthetic patient id, birth date, sex, an opaque
region code and an encounter count. The exact release, commands and hashes are in
`data/MANIFEST.json`.

All patients are synthetic. No real person is described.

`data/lexicon/` was written by the build agent for this repository.
